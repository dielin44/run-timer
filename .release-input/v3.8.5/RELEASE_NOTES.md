# 跑單大獅 3.8.5

## 主要更新

- 強化跑單紀錄可靠性：主畫面改為單一入口，通知與浮動獅頭都回到同一個 MainActivity；背景切換不再由舊畫面整份覆寫紀錄。
- 紀錄改用 SQLite 版本化交易保存，加入 revision 檢查、同代鏡像與完成訂單索引；舊畫面不能覆蓋新版本，已完成訂單不能無故消失或改寫關鍵時間、金額及里程。
- 進單、取餐、送達與取消均先完成同步儲存，再更新 GPS 狀態及畫面；中斷後可依已提交紀錄重建追蹤狀態。
- 成果新增每筆訂單的進單與送達時間，圖片及 Excel 同步顯示至分鐘；跑單計時與計價仍保留秒級精度。即時訂單明細不增加這兩個時間。
- 浮動獅頭點擊後直接開啟主畫面，不再顯示詢問視窗。
- 活動只展開進行中及結束未滿三小時的項目；其餘每個活動收納成一個暗紫色可點擊按鍵，以兩行顯示活動日期與開始、結束時間。收納不是刪除，歷史按鍵到結束日 23:59 才移除。
- 加碼活動管理的「＋新增活動」改為彩色粗體，活動之間加入分隔線。
- 理想費用改為距離結算後加 45 元；低於預計顯示藍色、高出 1～15 元顯示橘紅色、高出 16 元以上顯示金色，並套用至總計、成果、訂單明細及成果圖片。
- 本日速覽項目名稱為藍色、數據維持白色，新增扣除活動加碼與小費後的平均時薪、平均分薪。
- 成果圖片提高解析度，Excel 新增進單與送達時間欄位。

- 8 組純 Java 規則測試與 10 項 Android 35 模擬器資料庫／生命週期測試全部通過。
- APK 已通過 zipalign 與 APK Signature Scheme v2／v3 驗證。
- 套件名稱維持 `tw.com.deliverylaw.timer`，versionCode 34；簽章憑證與 v3.8.4 相同，可直接覆蓋安裝並保留資料。
