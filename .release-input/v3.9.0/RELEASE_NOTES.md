# 跑單大獅 3.9.0

## 主要更新

- 新增「下載更新」按鍵，可重新下載官方測速資料；資料檢查通過後才替換，更新失敗時保留原資料。
- 內建 2026-09-15 取得的官方資料，共 1,895 筆，其中 56 筆含區間測速標記。
- 區間測速獨立分類，首頁、背景浮動橫幅及通知都會顯示「區間測速」，並使用對應錄音。
- 預警距離依目前車速切換：低於 70 km/h 為 600 公尺，達 70 km/h 為 1 公里。
- 新增「關閉 GPS／開啟 GPS」。關閉後停止本 App 的定位、測速偵測與里程記錄，保留已儲存成果。
- 最下方新增「關閉跑單大獅」；確認後停止定位、測速提醒與背景服務。
- 改善 GPS 更新頻率、方向判斷與漂移處理，降低漏掉前方測速點及警示閃爍的情況。
- 保留原有跑單紀錄、活動加碼、成果匯出及語音功能。

## 安裝

版本：3.9.0（versionCode 39），套件名稱：`tw.com.deliverylaw.timer`。沿用既有簽章，可覆蓋安裝並保留資料。

首次使用請允許精確位置及通知；若要在其他 App 上方顯示測速資訊，另需允許「顯示在其他 App 上層」。

## 測速功能範圍

區間測速依官方代表座標提前提醒，沒有整段平均速度計算。官方資料可能不含臨時、移動式或尚未登錄的測速點，實際路況以現場標誌為準。本版沒有串接神盾後台。
