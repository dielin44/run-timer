# 跑單大獅 3.8.0

本版本已完成實機測試。

- 訂單卡片滿載後會自動顯示下一張，支援最多 12 張同時進行中的訂單卡片。
- 加碼活動新增日期設定，可預先建立未來或跨日活動。
- 支援多個活動同時存在及時間重疊，不再互相覆蓋。
- 活動訂單以進單時間判定；活動期間進單後，不限制必須在一小時內完成。
- 活動新增修改與刪除功能，修改時會保留原設定供調整。
- 活動結束後只顯示可點擊的「結束」，可開啟活動跑單紀錄；於活動結束日 23:59 清除顯示。
- 本日速覽改為單一卡片內左右兩欄、向下延伸，只需上下滑動，並放大文字及改善裁切。
- 本日速覽與成果表滑動區域分離，避免查看訂單紀錄時成果表干擾速覽畫面。

APK 已核對版本、簽章與 ZIP 對齊，可直接覆蓋 v3.7.3 安裝並保留資料。
