# 跑單大獅 3.8.8

## 主要更新

- 首頁訂單卡片上方新增常駐測速卡，直接顯示目前速度、道路限速、測速距離與設定入口，不必進入其他頁面查看。
- 測速功能改為 App 開啟後全程運作；即使尚未進單、兩趟之間或最後一單已完成，固定式測速偵測仍持續執行。跑單里程仍只會在有未完成訂單時累積。
- 內建全臺固定式測速資料快照共 1,896 筆，涵蓋各主要縣市、國道、金門與澎湖，不是只有臺中地區。
- GPS 更新頻率提高至約每 0.75 秒，最低位移設為 0 公尺；方向判定門檻降低，以支援步行速度測試。
- 桌面與其他 App 上方的浮動測速條改用更深、不透明的底色；欄位名與數值放大加粗，加入文字陰影及較粗的藍／橘／紅色外框，改善淺色與複雜背景下的辨識度。
- 測速設定可調整超速提醒容許值 0～10 km/h，並可獨立開關測速語音。
- 直接從指定影片裁切、重組 27 個 OGG 語音檔：固定式測速播放「小心！有測速」，區間測速播放「注意！有區間測速」；顯示速度達限速加 15 km/h 以上時改播較強烈版本。
- 語音涵蓋限速 30、40、50、60、70、80、90、100、110 km/h；全臺資料中唯一一筆限速 25 km/h 測速點以手機 TTS 後備播報。
- 無浮動視窗權限時，改用高優先通知與語音提醒；未授權精確定位時，首頁會明確提示用途。

## 測速資料說明

目前提供官方固定式測速設置點資料，不包含臨時移動式測速。資料可能晚於現場增設、撤除或速限變更，請以道路標誌與現場規定為準；勿為測試刻意超速。
